퀄리저널 관리자: 초딩 운영자 관리 매뉴얼

목표: “손 안 대고 항상 켜지는 관리자 서버”를 쉽게 운영합니다. (도커 없이 PowerShell+작업 스케줄러 방식)

핵심 요약

서버 실행: start_admin_task.ps1가 server_quali:app을 Uvicorn으로 띄웁니다. 기본 포트는 8080, 점유 시 8010으로 자동 전환.

자동 기동: 로그인 시 QualiAdmin 예약 작업이 자동 실행.

자가 복구: QualiAdmin-Health가 5분마다 상태를 확인하고 꺼져 있으면 다시 켭니다.

로그: admin\logs\server_YYYYMMDD.out/err.log에 일자별 저장(7일 보관).

하루 운용 체크리스트 (3단계)

  1. 상태 확인
    PowerShell에서 아래 한 줄을 실행합니다.
    Invoke-WebRequest "http://127.0.0.1:8080/api/status" -Headers @{ "X-Admin-Token"="devtoken" } -UseBasicParsing
    8080이 안 되면 8010으로 다시 시도합니다.
  2. 로그 확인
    gc "C:\Users\user\Desktop\퀄리저널\admin\logs\server_$(Get-Date -Format yyyyMMdd).out.log" -Tail 50
  3. 헬스 수동 실행(선택)
    schtasks /Run /TN "QualiAdmin-Health"

켜기 / 끄기

지금 바로 켜기

powershell -ExecutionPolicy Bypass -File "C:\Users\user\Desktop\퀄리저널\admin\start_admin_task.ps1"

8080이 바쁘면 자동으로 8010으로 켭니다.

완전히 멈추기

Stop-ScheduledTask -TaskName "QualiAdmin"
schtasks /Delete /TN "QualiAdmin-Health" /F

포트만 비우고 싶으면 Stop-Process -Id <PID> -Force.

문제 해결 5분 레시피

1) 포트 충돌(WinError 10048)

Get-NetTCPConnection -LocalPort 8080 -State Listen
Stop-Process -Id <PID> -Force

다시 start_admin_task.ps1 실행.

2) 응답 없음

schtasks /Run /TN "QualiAdmin-Health"

10초 후 /api/status 재확인.

3) 로그에서 오류 보기

gc "...\admin\logs\server_YYYYMMDD.err.log" -Tail 100

예약 작업 관리

로그온 자동 기동(등록됨)

작업 이름: QualiAdmin

Start-ScheduledTask -TaskName "QualiAdmin"

5분 헬스체크(등록됨)

작업 이름: QualiAdmin-Health

schtasks /Run /TN "QualiAdmin-Health"
schtasks /Query /TN "QualiAdmin-Health" /V /FO LIST

FAQ

Q. 8080 말고 다른 포트로 고정하고 싶어요.
A. start_admin_task.ps1 실행 시 -Port 8010 처럼 인자를 줄 수 있습니다.

Q. 토큰을 바꾸려면?
A. 스크립트 인자 -AdminToken, -ApiToken 또는 사용자 환경변수로 저장하세요.

Q. 브라우저에서 접속 주소는?
A. http://127.0.0.1:8080/ (우회 시 8010).
