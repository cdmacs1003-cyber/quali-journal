# Answer Evidence Contract

Packet: T-A1-07SOU_R9ZBY_TRACK_A_SAMPLE_QA_MATERIALIZATION_APPROVAL_PACKET
Scope: Track A Sample QA / E2E Answer Evidence ProofPack

## Purpose

Define the contract that future sample QA and E2E answer evidence must satisfy before any Track A or Beta readiness claim can be considered.

## ANSWERED Contract

Every ANSWERED sample must include:

| Field | Requirement |
|---|---|
| result_status | OK or equivalent safe answer status |
| answer_status | ANSWERED |
| evidence_id | required and non-empty |
| bridge_trace_id | required and non-empty |
| safe_summary | required learner-facing content |
| answer | equal to or derived only from safe_summary |
| raw_text_policy | SUMMARY_ONLY or stricter |
| raw_text_included | false |
| internal_path_included | false |
| feedback_candidate_required | false unless answer is downgraded for review |

## HOLD or DENIED Contract

Every HOLD or DENIED sample must include:

| Field | Requirement |
|---|---|
| result_status | HOLD or DENIED |
| answer_status | HOLD or DENIED |
| hold_reason | required safe learner-facing reason |
| bridge_trace_id | required when generated by Bridge, otherwise explicitly NOT_AVAILABLE |
| feedback_candidate_required | true unless a documented policy denies feedback creation |
| feedback_queue_item | required in future execution proof when feedback is materialized |
| raw_text_included | false |
| internal_path_included | false |

## Prohibited Answer Surfaces

Future answer evidence must not expose:

- paid standard raw text
- raw prompt
- raw query
- raw answer
- internal repository path
- local route or local file path
- secret-like value
- administrator-only detail to learner role
- Track A PASS escalation
- Beta PASS escalation
